Transparent paper lines (experiment)
====================================

Integrated grid presets with "Grid lines: reveal paper" (PT_FUSED_TRANSPARENCY,
0=Off, 1=Transparent). Shaders: handheld/shaders/pixel_transparency_experiments/
v2.4-transparent-lines/. See its README for the RPC cost that led to removing
the option from the production presets in ../../pixel_transparency/.

  pixel_transparency-<grid>.slangp
  sunlight_shimmer-<grid>.slangp
    <grid>: authentic_gbc_fast, lcd-grid-v2, lcd1x, lcd3x, simpletex_lcd, zfast_lcd
