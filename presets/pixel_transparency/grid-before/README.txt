Grid before Pixel Transparency / Sunlight Shimmer
================================================

These presets reference the unchanged standard presets one folder above.
The LCD grid is rendered first; transparency and sunlight are applied over it.
Choose pixel_transparency-* for plain transparency or sunlight_shimmer-*.

LCD1x, LCD3x, LCD Grid v2, Simpletex LCD and zfast LCD are included.
Plain transparency: 4 passes. Sunlight Shimmer: 6 passes.
For the opposite placement, choose the same filename in ../grid-after/.
See ../PRESETS.txt for the differences and performance limitations.
