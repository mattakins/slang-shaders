# Pixel Transparency authentic_gbc_fast performance compare

Self-contained presets for comparing Pixel Transparency versions on weaker GPUs.

- `pixel_transparency_1.1-authentic_gbc_fast.slangp` from `bb2899e5`
- `pixel_transparency_2.0-authentic_gbc_fast.slangp` from `d695c9b7`
- `pixel_transparency_2.1-authentic_gbc_fast.slangp` from `c6a89e16`
- `pixel_transparency_2.2-authentic_gbc_fast.slangp` from `upstream/master`

All four presets use the same bundled `authentic_gbc_fast` files from `upstream/master` so the comparison mostly isolates Pixel Transparency. v2.1 and v2.2 include their matching `pt_base.inc` files.
